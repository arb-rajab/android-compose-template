# Contributing

## Workflow

- **Branching:** trunk-based. Branch from `main` as `feat/<slug>`, `fix/<slug>`,
  `chore/<slug>` or `sec/<slug>`.
- **Commits:** [Conventional Commits](https://www.conventionalcommits.org/)
  (`feat:`, `fix:`, `docs:`, `test:`, `ci:`, `refactor:`, `chore:`).
- **Pull requests:** pass CI (lint, tests, security scans) and use the PR template.
- Open an issue before a large change; small fixes can go straight to a PR.

## Development setup

See `README.md` for the stack-specific commands to build, lint and test.

## Reporting security issues

See [`SECURITY.md`](SECURITY.md). Do not use public issues for vulnerabilities.
