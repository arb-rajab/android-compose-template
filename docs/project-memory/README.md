# Project memory

Empty scaffold. Use this folder for durable project context that outlives a single
working session. Suggested files (create them as they become useful):

- `00-project-brief.md` - what the project is and who it is for
- `01-scope-and-non-goals.md` - what is in and out of scope
- `02-architecture.md` - how the pieces fit together
- `03-testing-strategy.md` - what is tested where, and what cannot be tested
- `04-decisions.md` - architecture decision records (one entry per decision)
- `05-backlog.md` - planned work
- `06-session-handoff.md` - latest state, newest entry at the bottom

Keep each file short and grep-friendly; split a file when it grows past a few hundred lines.
